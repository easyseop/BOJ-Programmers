# 일본어 단어장

JLPT 교재 단어를 담은 단어장 웹앱. **`index.html` 하나만 열면** 바로 동작합니다.

## 기능
- **목록**: 분류 필터(음독명사/훈독명사) · `모두/즐겨찾기/미암기` 필터 · 검색(단어·읽기·뜻·**로마자**)
- **카드**: 플래시카드. **일→한 / 한→일 방향 전환**, 이전/다음 이동, 외움/모름
- **퀴즈**: 4지선다 (뜻 맞추기 / 읽기 맞추기), 정답 시 발음 재생
- **진도 저장**: 즐겨찾기·암기 체크를 브라우저(localStorage)에 저장 · 진도바
- **발음 듣기**(TTS, ja-JP) · **다크 모드** · 모든 단어에 후리가나

## 단어 추가하는 법
`words.py`의 `WORDS` 리스트에 한 줄씩 덧붙이면 됩니다.

```python
("写真","しゃしん","사진","음독명사","CH5"),
#  표기   읽기      뜻      분류        챕터
```

그다음 다시 빌드:
```bash
python3 build.py   # words.py -> index.html
```
- 분류(`음독명사` 등)는 자유롭게 추가하면 목록 필터 칩이 자동으로 생깁니다.
- 챕터(`CH5`)도 자유 문자열입니다. **챕터가 2개 이상이면 챕터 필터 칩이 자동으로 나타납니다.**
- 표기+읽기가 같은 단어가 두 번 들어가면 빌드 때 ⚠️ 경고가 뜹니다.

## 현황
- **63단어** (음독명사 60 · 훈독명사 3) — 교재 **CH5** 명사 파트
- 사진 하단이 잘려 훈독명사는 일부만 수록됨 (`支度` 등 추가 필요)

## 구조
```
vocab-app/
├─ index.html    ← 빌드 산출물 (이것만 열면 동작)
├─ build.py      ← words.py -> index.html
├─ template.html ← UI 템플릿 (`/*__DATA__*/` 자리에 데이터 주입)
└─ words.py      ← 단어 데이터
```
`index.html`은 직접 고치지 말고 `words.py`/`template.html`을 고친 뒤 `build.py`로 재생성하세요.
