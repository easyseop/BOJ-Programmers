# 일본어 공부 (통합 앱)

**한자앱 + 단어장을 하나로 합친** 단일 HTML 웹앱. `index.html` 하나만 열면 동작합니다.

🔗 **https://claude.ai/artifact/YWZntPxP8dosQ1uBAsUt6J**

## 구성
상단에서 **📚 한자 / 📖 단어장** 모드를 전환합니다. 각 모드 안에 `목록 / 카드 / 퀴즈` 탭이 있습니다.

### 📚 한자 (984자 · JLPT N5~N2)
- 등급 필터(전체/N5/N4/N3/N2) · 즐겨찾기/미암기 필터 · 검색(한자·뜻·읽기·**로마자**·영어)
- 상세: 기본정보 → 어원 해설 + 💡암기 꿀팁 → 음독 상세 → 훈독 상세 (대표단어 후리가나+한국어)
- 이전/다음 이동(←/→ 키), 획순(KanjiVG, 온라인 시)
- 플래시카드(읽기별 예시 단어 2개 + 뜻), 퀴즈

### 📖 단어장 (140개 · 교재 CH5)
- 챕터 필터(**챕터 2개 이상일 때 자동 표시**) · 품사 필터 · 즐겨찾기/미암기 · 검색(단어·읽기·뜻·로마자)
- **단어 속 한자에 점선 밑줄 → 누르면 같은 앱에서 한자 상세가 열림** (외부 이동 없음)
  상세 위에 `← 단어장으로 돌아가기` 버튼이 뜹니다
- 플래시카드(**일→한 / 한→일 방향 전환**), 퀴즈

### 공통
🔊 발음 듣기(TTS) · 🌙 다크 모드 · 진도 저장(localStorage) · 진도바

## 빌드
```bash
cd study-app && python3 build.py   # ../kanji-app/*, ../vocab-app/words.py -> index.html
```
데이터는 기존 두 폴더를 그대로 참조합니다. **수정은 원본 데이터 파일에서** 하세요.

| 파일 | 내용 |
|---|---|
| `../kanji-app/facts.json` | 984자 읽기/획수/등급/영어뜻 |
| `../kanji-app/ko.py` | 한국어 훈음 |
| `../kanji-app/rich.py` | 어원 + 음훈독 대표단어 |
| `../kanji-app/tips.py` | 암기 꿀팁 |
| `../vocab-app/words.py` | 단어 `(표기, 읽기, 뜻, 품사, 챕터)` |
| `study-app/template.html` | 통합 UI 템플릿 |

## 단어 추가 (다음 챕터)
`../vocab-app/words.py`에 덧붙이고 다시 빌드하면 끝입니다.
```python
("単語","たんご","단어","음독명사","CH6"),
```
→ CH6이 생기는 순간 **챕터 필터 칩이 자동으로 나타납니다.**

## 현황
- 한자 **984 / 984** 상세·꿀팁 완료 (누락 0)
- 단어 **140개** (CH5: 음독명사 60 · 훈독명사 7 · 동사 32 · い형용사 12 · な형용사 8 · 부사 11 · 가타카나어 10)
- 단어 속 한자 중 링크 안 되는 글자 **17자** (전부 N1급이라 한자 데이터 없음)
