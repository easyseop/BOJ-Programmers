# 일본어 공부 (통합 앱)

**한자앱 + 단어장을 하나로 합친** 단일 HTML 웹앱. `index.html` 하나만 열면 동작합니다.

🔗 **https://claude.ai/artifact/YWZntPxP8dosQ1uBAsUt6J**

## 구성
상단에서 **📚 한자 / 📖 단어장** 모드를 전환합니다. 각 모드 안에 `목록 / 카드 / 퀴즈` 탭이 있습니다.

### 📚 한자 (1098자 · JLPT N5~N2 전체 + N1 일부)
- 등급 필터(전체/N5/N4/N3/N2/N1(일부)) · 즐겨찾기/미암기 필터 · 검색(한자·뜻·읽기·**로마자**·영어)
- 상세: 기본정보 → 어원 해설 + 💡암기 꿀팁 → 음독 상세 → 훈독 상세 (대표단어 후리가나+한국어)
- 이전/다음 이동(←/→ 키), 획순(KanjiVG, 온라인 시)
- 플래시카드(읽기별 예시 단어 2개 + 뜻), 퀴즈(오답 보기는 같은 등급 한자에서)

### 📖 단어장 (988개 · 교재 CH1 ~ CH7)
- **챕터 선택 바** (단어장 맨 위, `챕터 1 ~ 챕터 7 / 전체`): 고른 챕터의 단어만 **목록·카드·퀴즈 모두**에 나옴. 마지막 선택은 기억됨
- **여러 챕터 모아보기**: 켜면 챕터를 누를 때마다 추가/빼기 (예: `챕터 1~3`, `챕터 1·3·5`). 목록·카드·퀴즈 모두 선택한 챕터들만, 챕터 순서대로
- 품사 필터 · 즐겨찾기/미암기 · 검색(단어·읽기·뜻·로마자)
- **예문 1,369개** (단어 988개 전부): 실생활에서 쓰는 문장, 동사·형용사는 **활용형이 다른 예문 2개**
  - 카드 뒷면 / 목록의 💬 버튼에서 보기, 공부 단어는 실제 활용형 그대로 강조 + `憧れる → 憧れていた (~하고 있었다)` 같은 활용 설명
  - 🔊 예문 전체 듣기, 퀴즈 `예문 빈칸`(문장 속 활용형 고르기) · `예문 듣기`(문장 듣고 뜻 고르기)
  - 데이터: `../vocab-app/examples/chN.py`, 검사: `python3 ../vocab-app/check_examples.py CH1`
- **단어 속 한자에 점선 밑줄 → 누르면 같은 앱에서 한자 상세가 열림** (외부 이동 없음)
  상세 위에 `← 단어장으로 돌아가기` 버튼이 뜹니다
- 플래시카드(**일→한 / 한→일 방향 전환**). 뒷면에 **단어 속 한자 풀이** (`大使館` → `大 큰 대` `使 부릴 사` `館 집 관`, 누르면 한자 상세)
- 퀴즈 4가지 방식
  - **객관식**: 단어 보고 뜻/읽기 고르기 (오답 보기는 **같은 품사**·같은 챕터, 읽기는 **비슷한 발음** 위주)
  - **뜻 보고 단어**: 한국어 뜻 → 일본어 표기 고르기
  - **읽기 직접 쓰기**: 히라가나·가타카나·로마자 입력 모두 채점 (장음 생략 `jokyo`, な형용사 だ 생략 허용)
  - **듣고 고르기**: 발음 듣고 뜻 고르기 (이 모드에서만 문제 시작 시 소리 재생)
  - 틀리면 정답 + 한자 풀이를 보여주고 `다음 문제` 버튼, 맞히면 자동 진행
  - **✗ 틀린 단어**: 퀴즈에서 틀린 단어만 모아 다시 풀기 (맞히면 목록에서 빠짐, 저장됨)

### 📝 문법 (주제별 · 현재 **경어** 9문형)
- **설명**: 주제 한눈에 보기(존경어·겸양어·정중어 비교) → 문형별 `뜻 / 접속 / 쉬운 예문(🔊) / 💡 팁`, 특별 경어 표
- **카드**: 앞면 문형 → 뒷면 뜻·접속·예문 / 특별 경어 표 카드(기본형 → 존경어·겸양어)
- **퀴즈**: `빈칸 고르기`(JLPT 문법1 유형, 해설 포함) · `경어 바꾸기`(표에서 출제, 반대쪽 경어를 함정 보기로) · `★ 문장 배열`(듀오링고식 조각 맞추기, 함정 조각 1개)
- 예문 속 한자도 누르면 한자 상세 (`← 문법으로 돌아가기`)

### 공통
🔊 발음 듣기(TTS) · 🌙 다크 모드 · 진도 저장(localStorage) · 진도바

## 빌드
```bash
cd study-app && python3 build.py   # ../kanji-app/*, ../vocab-app/words.py, ../grammar/grammar.py -> index.html
```
데이터는 기존 두 폴더를 그대로 참조합니다. **수정은 원본 데이터 파일에서** 하세요.

| 파일 | 내용 |
|---|---|
| `../kanji-app/facts.json` | 1098자 읽기/획수/등급/영어뜻 |
| `../kanji-app/ko.py` | 한국어 훈음 |
| `../kanji-app/rich.py` | 어원 + 음훈독 대표단어 |
| `../kanji-app/tips.py` | 암기 꿀팁 |
| `../vocab-app/words.py` | 단어 `(표기, 읽기, 뜻, 품사, 챕터)` |
| `../grammar/grammar.py` | 문법 (주제·문형·예문·빈칸문제·특별경어 표) — 형식은 파일 상단 주석 참고 |
| `study-app/template.html` | 통합 UI 템플릿 |

## 단어 추가 (다음 챕터)
`../vocab-app/words.py`에 덧붙이고 다시 빌드하면 끝입니다.
```python
("単語","たんご","단어","음독명사","CH8"),
```
→ 챕터 선택 바에 **`챕터 8` 버튼이 자동으로 추가됩니다** (번호순 정렬).
